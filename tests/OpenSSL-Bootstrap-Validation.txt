Reproduction
This optional archive-regression suite uses the original offline OpenSSL subset
ZIP as a historical fixture. That ZIP is not distributed in the public repository.
It is separate from the default GitHub Actions test suite.
Use tests/OpenSSL-Bootstrap.Tests.ps1 with explicit local arguments:
-KitRoot <checkout>
-SourceArchive <verified Git-2.56.1-64-bit.tar.bz2>
-LegacyArchive <verified openssl-git-2.56.1-windows-x64.zip>
-TarExecutable <local tar executable>
Alternatively supply QN90B_TEST_KIT, QN90B_TEST_GIT_ARCHIVE,
QN90B_TEST_LEGACY_OPENSSL, and QN90B_TEST_TAR.
The script imports dependency function definitions only and uses isolated temporary
folders. It does not call Install-Qn90bDependencies, Worker, or any television tool.

Platform behavior
The production resolver uses System32/tar.exe in a 64-bit process and Sysnative
from a 32-bit process on 64-bit Windows. It never resolves tar from PATH.
The exact selected members are passed after --, with ProcessStartInfo argument
quoting and concurrent stdout/stderr draining. Extraction has a 180-second timeout.
An absent tar or a tar build unable to read bzip2 fails before replacing an existing
installation. There is no fallback installer or post-install execution.

Encoding
Dependencies.ps1 and the test script retain UTF-8 BOM and CRLF.
OpenSSL-Provenance.json deliberately preserves its original 827 bytes.
