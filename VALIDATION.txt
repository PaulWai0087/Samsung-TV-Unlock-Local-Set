BEHAVIOR
Detection uses temporary root to run the unchanged read-only helpers and
requires authenticated UID/EUID 0, complete returned state, expected model,
firmware evidence and consistent per-helper results. GUI opening/Setup does
not perform a TV parameter write. Clicking a change action rechecks current
state before dispatching the required proven stage host(s).

Singapore: CHI13 -> Stage1 Apply -> Stage2 Apply; CHI0 -> Stage2 Apply;
SG0 -> no factory write.
Full China recovery: SG0 -> Stage2 Restore -> Stage1 Restore;
CHI0 -> Stage1 Restore; CHI13 -> no factory write.
Recovery requires actual matching original backups, never inferred originals.
Each phase reports readback and preserves any returned rollback fields.
A failed phase stops further writes and does not undo an earlier successful
phase automatically. Missing primary evidence is unknown, not success.

The supported target is Local Set AD_SIN2. The kit does not replace firmware
or guarantee every app/service will work. A normal reboot followed by another
read is the way to verify the post-reboot state on the actual TV.
